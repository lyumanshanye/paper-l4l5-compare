# Paper L4/L5 Compare

Standalone review page for 30 openly retrieved academic papers processed by DeepSeek-V4-Flash through the L4 cleaning and L5 cognitive rewrite stages.

- Open the GitHub Pages site at `index.html`.
- `results/` contains the model outputs, paper samples, and source manifest.
- `scripts/` contains the reproducible fetch, sampling, inference, and page-generation scripts.

The paper sources are traceable by CSV row, DOI, OpenAlex record, and public PDF URL in the manifest.
